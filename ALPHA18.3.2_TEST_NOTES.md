# Alpha 18.3.2 Suitability Colour Coding

The calendar grid stays single-line and uncluttered.

Clicking/selecting a crop now shows a colour-coded suitability badge in the
right-hand regional profile panel:

- Green: Excellent / Good
- Amber: Normal / Marginal
- Red: Poor / Unsuitable

The same detail area shows whether the crop calendar is sourced from:
REGIONAL, MAP, or FALLBACK.

The regional Apply / NPC regeneration transaction is unchanged.
