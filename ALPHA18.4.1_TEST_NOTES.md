# Alpha 18.4.1 — Environmental Status UI

Player-facing MoistureSystem status is now:

- Green: ENVIRONMENTAL MATCH
- Amber: ENVIRONMENTAL MISMATCH
- Amber: CUSTOM / UNMAPPED ENVIRONMENT
- Grey: MOISTURESYSTEM NOT ACTIVE

The detail line shows the environmental profile and whether MoistureSystem's
weather override is ON/OFF.

No gameplay transaction logic changed.
