# Alpha 18.3.3 Suitability Text Colour Hotfix

The Alpha 18.3.2 badge attempted to colour a drawable background on a Text
element, which does not render as intended in the FS25 GUI.

Alpha 18.3.3 colours the suitability text directly:

- Excellent / Good: green
- Normal / Marginal: amber
- Poor / Unsuitable: red

The selected crop and Calendar source labels remain unchanged.
The regional calendar and NPC regeneration transaction are unchanged.
