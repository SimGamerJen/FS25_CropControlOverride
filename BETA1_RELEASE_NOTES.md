# Crop Control Override 2.1.0.0-beta.1

Beta 1 marks the feature-complete public test build for the 2.1 development cycle.

Major additions since 2.0.3.6 include:
- Custom Crop Calendar editor with preview/apply/restore workflow and visual legend.
- Regional crop profiles, custom XML profiles, crop suitability and unsuitable-crop policy.
- Guarded NPC field regeneration and existing-field reconciliation.
- Read-only MoistureSystem environmental status integration.
- Native Crop Calendar hiding for crops disabled in CCO.
- Rules-table Weight column and Show Disabled visibility toggle.
- Automatic starter template creation for custom regional profiles.
- Dedicated-server / multiplayer fixes and additional UI, diagnostics and localisation work.
- Farm Sim Manager CCO Integration API 1.2 compatibility retained.

Beta focus:
- stability;
- dedicated-server / multiplayer validation;
- compatibility testing;
- UI/edge-case corrections;
- no major new features unless required to resolve a release blocker.
